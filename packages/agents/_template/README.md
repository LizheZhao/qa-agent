# Agent template

all TODO markers, package metadata, contracts, and tests. Keep private subgraphs with the parent.

agent's tools and routing-safe capabilities, use the core `AgentDependencies` boundary, and keep owned
prompt text in `prompts.py` rather than graph nodes.
